# Hotel Reservation Management System

Design and Implementation of a Hotel Reservation Management System  
ระบบจัดการจองโรงแรม设计与实现

## Project Overview
A web-based system for managing hotel room reservations, check-in, check-out, and room status.

## User Roles
- Guest: Register, login, search rooms, reserve, pay, view history, cancel, review
- Receptionist: View arrivals/departures, check-in, check-out, walk-in booking, update room status
- Administrator: Manage users, staff, room types, rooms, prices, reservations, reports, reviews

## Tech Stack
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: Spring Boot (Java)
- Database: MySQL

## Project Structure
- `frontend/` - Front-end source code
- `backend/` - Back-end source code
- `database/` - SQL scripts
- `docs/` - Diagrams and documents
